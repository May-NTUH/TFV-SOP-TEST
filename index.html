4 四、影像轉檔 SOP

1. Export FOVs images（轉出單張或多張 FOVs 影像）

  1. 選擇紅色標記旗幟，於影像視窗中點選欲個別轉檔之 FOVs（點選出現主旗 1 個＋副旗 8 個，九宮格排列）。
  2. 點選 Export → Export FOVs images。
  3. 設定存檔位置、檔名結構與圖片格式；選擇 All／Flags Only／Flags With Neighbors 決定輸出範圍。
  4. 建議勾選 Apply Illumination Correction；可加上比例尺（無法指定大小）。
  5. 點選 Save 完成輸出。

▲ 圖 4-1：Export FOVs Images 設定對話框與旗幟標記

備註：FOVs 原始檔為 JPG；因包含拼接計算範圍，實際單張 FOVs 會比拼圖中顯示範圍稍大。

2. Export region overview – Export region（轉出單張完整拼接全圖）

  1. 點選 Export → Export region overview。
  2. Basic 頁面：設定存檔位置、格式（JPG／BMP／PNG／TIFF）及影像壓縮程度；建議勾選 Apply Illumination Correction。
  3. Advanced 頁面：可勾選 Scale bar（標記比例尺）與呈現 Subregions 框選範圍標示及面積。
  4. 確認 Results 中預估的照片長寬與檔案大小後，點選 Export。

▲ 圖 4-2：Export Region Overview 基本與進階設定

備註：合適大小範圍內建議使用 JPG 做轉檔；Tiff 轉檔之照片顯示範圍可能與原先不同，後續需自行裁切。

3. Export region overview – Export only overviews from categories（轉出指定圈選範圍拼接全圖）

  1. 點選 Subregions → Manage Categories，輸入組別名稱並選擇框選線條顏色（不同組可分開輸出拼圖）。
  2. 於 Subregions 選單點選分組名稱，使用固定框選工具或手動框選工具（Add PolyLine）於照片上繪製區塊。
    ＊繪製時只能選擇及顯示單一分組名稱。
  3. 進入 Export region overview，選擇 Export only overviews from categories，於 Advanced 頁選擇欲輸出的組別後匯出。

3 三、功能鈕介紹

▲ 圖 3-1：頂部工具列功能配置圖

影像檢視縮放功能鈕

自訂縮放比例、100% 原尺寸 (1:1)、最佳觀察大小、全圖地圖顯示。

FOV 格線顯示

開啟或關閉 Field of View 網格邊界。

樣本範圍裁切顯示

顯示或遮罩樣本範圍外之區塊。

比例尺顯示

開啟右下角比例尺（例如 200 μm）。

螢光專屬功能

◎ 螢光顯示與亮度調整（Region Overlay）

  • 勾選各通道（DAPI／FITC／TEXAS／CY5 等）決定是否顯示螢光。
  • 可選擇螢光套色（Color），並用 Auto 或手動點擊 Range 調整強度。
  • 點擊 Range 開啟手動調整視窗：Lower 調高可降低 background；Upper 調低可增加 intensity。
  • 設定完成點 Apply 或 Apply & Close。

▲ 圖 3-2：螢光通道勾選、套色與強度手動調整

◎ Shading Correction

螢光影像一般建議不要開啟 Shading Correction（圖示「綠色 ON」代表未開啟）。

◎ Z-stack 顯示（檔案包含 Z 軸內容才會出現）

  • 按下開關鈕可啟用或關閉 Z 軸影像控制。
  • 拖動滑桿可選擇觀察不同 Z 軸影像。
  • 第 0 層為軟體將所有 Z 軸影像清楚部分結合成一張清晰之影像。

4 四、影像轉檔 SOP

1. Export FOVs images（轉出單張或多張非拼圖 FOVs 影像）

  1. 選擇紅色標記旗幟，於影像視窗中點選欲個別轉檔之 FOVs（主旗 1 個＋副旗 8 個，九宮格排列）。
  2. 點選 Export → Export FOVs images。
  3. 於「Please select what type of images you want to save」勾選 Overlay（多色螢光疊圖）和／或 Original（原始單色，可選 16-bit）。
  4. 選擇 All／Flags Only／Flags With Neighbors 決定輸出範圍。
  5. 螢光影像請勿勾選 Apply Shading Correction；可加上比例尺。
  6. 點選 Save 完成輸出。

▲ 圖 4-1：Export FOVs Images 設定對話框（含 Overlay／Original 選項）

備註：多色螢光疊圖以當下勾選開啟的顏色為主，如需不同組合需更改顯示後分多次轉出；實際單張 FOVs 會比拼圖中顯示範圍稍大。

2. Export region overview – Export region（轉出單張完整拼接全圖）

  1. 點選 Export → Export region overview。
  2. Basic 頁面：可選擇 Export region overlay（輸出多色螢光疊圖）或 Export region channels（輸出單色螢光影像，8-bit／16-bit）。
  3. 選擇 Export regions overviews 輸出全圖影像；螢光影像 Apply Shading Correction 請勿勾選。
  4. Advanced 頁面：可勾選 Scale bar 與呈現 Subregions 框選範圍標示。
  5. 確認 Results 清單後點選 Export。

▲ 圖 4-2：Export Region Overview（Overlay／Channel 輸出選項）

備註：多色螢光疊圖以當下勾選開啟的顏色為主；Tiff 轉檔之照片顯示範圍可能與原先不同，後續需自行裁切。

3. Export region overview – Export only overviews from categories（轉出指定圈選範圍拼接全圖）

  1. 點選 Subregions → Manage Categories，輸入組別名稱並選擇框選線條顏色。
  2. 於 Subregions 選單點選分組名稱，使用固定框選工具或手動框選工具於照片上繪製區塊。
    ＊繪製時只能選擇及顯示單一分組名稱。
  3. 進入 Export region overview，選擇 Export only overviews from categories，並可搭配 Overlay／Channel 輸出方式，於 Advanced 頁選擇欲輸出的組別後匯出。

▲ 圖 4-3：圈選分組建立與特定區域全圖輸出
