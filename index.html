4 四、影像轉檔 SOP

1. Export FOVs images (轉出單張或多張 FOVs 影像)

  1. 選擇紅色標記旗幟，於影像視窗中點選欲個別轉檔之 FOVs（點選出現主旗 1 個 + 副旗 8 個九宮格排列）。
  2. 點選 Export → Export FOVs images。
  3. 設定存檔位置、檔名結構與圖片格式，點選 Save。

▲ 圖 4-1：Export FOVs Images 設定對話框與旗幟標記

2. Export region overview (轉出單張完整拼接全圖)

  1. 點選 Export → Export region overview。
  2. 於 Basic 基本頁面設定存檔位置、格式（JPG/BMP/PNG/TIFF）及壓縮比例。
  3. 於 Advanced 進階頁面可勾選標記比例尺 (Scale bar) 與呈現 Subregions 框選範圍。

▲ 圖 4-2：Export Region Overview 基本與進階設定

3. Export only overviews from categories (轉出指定圈選範圍拼接全圖)

  1. 點選 Subregions → Manage Categories 新增框選組別與線條顏色。
  2. 使用固定框選工具或手動繪製工具（Polyline）圈選指定區域。
  3. 進入 Export region overview 勾選 Export only overviews from categories 後匯出。
